### Installation & Usage Procedure

Before executing servicing tasks on MediaTek devices, ensure the necessary MTK VCOM drivers and LibUSB filter drivers are installed on your computer.

1. **Install MediaTek USB Drivers:** Driver Setup.
Download and install the MediaTek VCOM driver package and LibUSB filter driver. Reboot Windows to establish valid COM port recognition.

*Verification:* Connect a turned-off device while holding Volume keys to ensure **Windows Device Manager** momentarily registers a MediaTek USB Port without any yellow exclamation warnings.


2. **Connect Dongle and Run Setup:** Hardware Connection.
Plug your UMT / UMT Pro hardware dongle into a USB port. Extract `UMTv2_UMTPro_UltimateMTK2_3.9.zip`, right-click `Setup_UMT_MTK_Edition_3.9.exe`, and select **Run as Administrator**.

*Verification:* The UltimateMTK2 dashboard opens, displaying smartcard serial validation in the diagnostic log window.


3. **Select Function and Connect Device:** Servicing Execution.
In the software, choose your target operation (e.g., **Reset FRP**, **Format FS**, or **Flash Scatter**). Power off the target phone completely, click **Execute** in the tool, and connect the phone via USB cable while holding **Volume Up + Volume Down**.

*Verification:* Observe the operation status panel until the process log reads `Operation Finished: OK`.
